# InkaVoice — Pantalla Login (Expo / React Native)

Componentes listos para copiar en tu app Expo Go.

## Archivos

| Archivo | Descripción |
|---------|-------------|
| `components/BrandHeader.tsx` | Logo con diamante dorado, InkaVoice y eslogan |
| `screens/LoginScreen.tsx` | Pantalla completa de inicio de sesión |
| `theme/colors.ts` | Colores de la marca |

## Integración

1. Copia la carpeta `mobile/` dentro de tu proyecto Expo.
2. Instala: `npx expo install react-native-safe-area-context`
3. Importa `LoginScreen` en tu ruta de login.
